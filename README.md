# ClassDiagram-Tool

C++ 저장소를 클래스 다이어그램으로 그리고, AI와 대화하며 **다이어그램 위에서만** 설계를 바꿔보는 로컬 웹 툴.

- 처음 열 때 한 번만 헤더를 읽어 다이어그램을 만듦
- 이후의 편집(직접 편집·AI 채팅)은 다이어그램에만 반영되고 소스 코드는 그대로 유지됨
- 코드에서 온 항목과 설계로 추가·수정·삭제 예정인 항목이 색으로 구분되어, 다이어그램이 곧 "코드 대비 설계 diff"가 됨

---

## 주요 기능

### 다이어그램
- C++ 헤더(`.h` `.hpp` `.hh` `.hxx` `.inl`) 파싱
  - 클래스·구조체·enum·함수 namespace, 상속, 멤버(필드·함수), 접근 지정자
  - 본문에서 클래스를 정의하는 function-like 매크로는 펼쳐서 인식함 (예: `SHADER_STATE(VSState, ShaderState)`)
  - 필드 타입으로 관계 추정: 값/unique 소유 → 합성, 컨테이너 → 집합, 포인터/참조/RefPtr → 연관
- 폴더 › 헤더 파일 단위 중첩 그룹 (클래스 3개 이상인 파일만 하위 그룹으로 분리)
- 그룹 안은 상속 트리 배치 (부모 위, 자식 아래), 형제 그룹도 상속 순서대로 위아래 정렬
- 직각 관계선 + 교차 지점 아치, 같은 대상으로 들어가는 선은 공통 버스선으로 합쳐 그림
- 그룹 접기·숨기기, 축소 단계별 텍스트 생략(LOD), 라벨 겹침 처리 (폴더 > 클래스명 > 파일명)
- 화면 밖 노드 컬링, 노드 마크업 캐시로 큰 다이어그램에서도 부드럽게 동작

### 편집
- 인스펙터(속성 편집기)
  - 플래그 토글: 추가 예정 / 수정 예정 / 검토 필요 / 삭제 예정
  - 상속(base) 추가·제거, 자식 클래스 추가, 박스 노트(박스 안에 한 줄 표시)
  - 멤버 표(접근 · 타입 · 이름)에서 멤버 추가·수정·삭제·복원
  - 관계 표 (상속 부모/자식 + 합성·집합·연관·의존, 근거 멤버)
- 클래스 메모: 클래스마다 여러 개 추가·삭제
  - 메모가 있으면 박스 왼쪽 위에 `메모 N` 배지 표시
  - 배지를 누르면 메모 목록(메모마다 1~2줄), 메모를 누르면 전체 내용이 펼쳐짐
- 플래그 칩 드래그 앤 드롭 (클래스 박스 또는 멤버 줄로)
- 코드와 다르게 수정한 부분은 주황 + ✎, 원래 코드 내용은 취소선으로 함께 표시
- `Ctrl+Z` / `Ctrl+Shift+Z` 편집 이력 (이동·자동 배치·플래그·인스펙터 편집, 새로고침 후에도 탭 단위로 유지)

### AI
- AI 채팅: 다이어그램 편집 도구로 클래스·멤버·관계를 추가/수정, 코드는 읽기 전용으로 참고
- 역할 추론: 클래스 선언과 대응 `.cpp`를 근거로 역할·책임·협력 클래스를 한국어/영어로 요약
- 일지 요약: 날짜별 커밋 diff + 설계 기록을 근거로 "코드에서 바뀐 것 / 바꿀 예정 / 다음 할 일" 정리

### 일지
- 날짜별 카드: git 커밋(파일·관련 클래스), 커밋 안 된 작업 파일, 설계 기록(직접/AI/재스캔), 메모, AI 요약
- 재스캔 시 코드에서 바뀐 항목을 자동 기록하고, 설계해둔 항목이 코드에 생기면 "설계대로 구현됨"으로 표시

### 그 밖의 기능
- 파일 경로 클릭 → VS Code에서 해당 줄 열기 / 다이어그램에서 그 파일의 클래스로 이동
- 클래스 찾기 시 카메라 이동 애니메이션
- `Ctrl+S`: 다이어그램 + 일지를 JSON 파일 하나로 저장 (처음엔 저장 위치 선택, 이후 같은 파일에 덮어씀)
- 오른쪽 패널 폭·상세 창 높이 드래그 조절

## 실행

```bash
git clone https://github.com/Winteradio/ClassDiagram-Tool.git
cd ClassDiagram-Tool
pip install -r requirements.txt   # API 키 방식을 쓸 때만 필요
python server.py                  # http://127.0.0.1:8765 이 브라우저로 열림
```

- `--port 9000`: 포트 변경
- `--no-browser`: 브라우저 자동 실행 안 함

브라우저에서:

**새 repo 스캔**
1. **📁**로 repo 폴더 선택 (또는 경로 직접 입력, 예: `C:\work\MyEngine`)
2. **스캔 폴더** 입력 (예: `Engine`, 여러 개는 쉼표로 구분, 비우면 repo 전체)
3. **스캔** → 처음이면 헤더를 읽어 다이어그램을 만들고, 이미 있으면 코드 변경만 반영함 (설계 항목·플래그·메모·위치는 유지)

**저장 파일 열기**
- **열기** → `Ctrl+S`로 저장한 JSON 선택 → 다이어그램과 일지를 불러옴
  - 연 파일이 이후 `Ctrl+S`의 저장 대상이 됨
  - 파일에 기록된 repo 경로가 이 PC에 없으면 repo 폴더를 다시 고르게 함
  - 이 repo의 작업 데이터가 이미 있으면 "파일 내용으로 덮어쓰기 / 지금 작업 유지" 중에서 고름

마지막으로 연 repo는 다음 실행 때 자동으로 복원됨. `build`, `external`, `third_party`, `vendor`, `.git` 같은 폴더는 스캔에서 제외됨.

## AI 연결

처음 열면 "Claude 환경에 연결할까?" 창이 뜨고, 나중에 **⚙ 설정 → AI 연결**에서 바꿀 수 있음.

### Claude Code (구독, API 키 불필요)
- 이 PC에 로그인된 Claude Code를 `claude -p`로 실행함
- `--restricted` 모드로 실행
  - 명령 실행 도구 제거, 사용자 설정 무시, 파일 도구는 대상 repo 안으로 제한
  - 코드는 `Read` / `Grep` / `Glob`으로 읽기만 가능, `Edit` / `Write` 불가
- 다이어그램 편집은 `mcp_diagram.py`(MCP stdio 서버)를 거쳐 로컬 서버로 전달됨
- 구독 사용량을 쓰므로, 이 모드에서는 클릭 시 자동 역할 추론이 기본으로 꺼짐

### Anthropic API 키
- ⚙ 설정에 키 입력 (브라우저 localStorage에만 저장, 로컬 서버로만 전송) 또는 `ANTHROPIC_API_KEY` 환경 변수
- [Claude Console](https://platform.claude.com)에서 크레딧 충전 필요 (Claude 구독과 별개)
- 기본 모델은 `claude-opus-5-5`이고, 설정에서 변경 가능

## 데이터 저장 위치

- 대상 repo에는 아무것도 쓰지 않음
- 다이어그램: `data/<repo이름>-<해시>.json`
- 일지(설계 기록·메모·요약): `data/<repo이름>-<해시>.journal.json`
- `data/`는 `.gitignore`로 이 레포 커밋에서 제외됨
- 공유·백업이 필요하면 `Ctrl+S`로 원하는 위치에 묶음 파일(JSON)을 저장

## 구조

| 파일 | 역할 |
|---|---|
| `server.py` | 로컬 HTTP 서버, 다이어그램 저장·재스캔 병합, 편집 도구, AI 호출(Claude Code / API) |
| `cppscan.py` | C++ 헤더 휴리스틱 파서 → 다이어그램 모델 |
| `journal.py` | 일지: git 조회(읽기 전용), 설계 기록, 날짜별 요약 프롬프트, 재스캔 diff |
| `mcp_diagram.py` | Claude Code 채팅용 MCP stdio 서버 (다이어그램 도구 노출) |
| `index.html` | UI 전체 (SVG 렌더링, 인스펙터, 채팅, 일지) |

## 한계

- 파서는 정식 C++ 파서가 아니라 중괄호·세미콜론 기반 휴리스틱임
  - 템플릿 특수화(`template<>`)는 건너뜀
  - 클래스를 정의하지 않는 매크로는 펼치지 않음
  - 관계는 필드 타입만 보고 추정함 (함수 매개변수 의존성은 다루지 않음)
- 로컬 사용 전용 (서버는 `127.0.0.1`에만 열리고 `application/json` 요청만 받음)
